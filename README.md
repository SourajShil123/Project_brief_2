# Library Management System

## Project Overview
The Library Management System is a web-based application developed using the MERN Stack. It is designed to manage books, members, borrowing, returns, and fines efficiently through a centralized platform.

## Project Domain
Education

## Technology Stack
- MongoDB
- Express.js
- React.js
- Node.js
